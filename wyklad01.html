Fundament #1 – HTML

Język HTML – Kręgosłup Każdej Strony

HTML (HyperText Markup Language) to język dokumentów tekstowych z komendami ujętymi w nawiasy ostre <znacznik>:

  • Otwarcie: <komenda>
  • Zamknięcie: </komenda>
  • Przeglądarka interpretuje plik .html i prezentuje ostateczny wygląd.
Kluczowe elementy struktury:
<!DOCTYPE html> – deklaracja wersji HTML5
<html lang="pl"> – korzeń + język dokumentu
<head> – metadane, tytuł, style (niewidoczne)
<body> – cała widoczna treść strony 
<!DOCTYPE html>
<html lang="pl">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width,
                   initial-scale=1.0">
    <title>Tytuł mojej strony</title>
    <link rel="stylesheet" href="styl.css">
  </head>
  <body>
    <h1>Witaj na mojej stronie!</h1>
    <p>To jest treść dokumentu.</p>
  </body>
</html>
HTML5 – Semantyka

HTML5 Semantyczny – Struktura, Którą Rozumie Przeglądarka i Google

Nowoczesny HTML używa znaczników semantycznych – mówią one co dany element oznacza, nie tylko jak wygląda:

<header> – nagłówek strony / sekcji
<nav> – nawigacja (menu)
<main> – główna treść (tylko raz na stronę!)
<article> – samodzielny artykuł / wpis blogowy
<section> – tematyczna sekcja treści
<aside> – sidebar, treści poboczne
<footer> – stopka strony / sekcji
<body>
  <header>
    <h1>Moja strona</h1>
    <nav>
      <ul>
        <li><a href="/">Strona główna</a></li>
        <li><a href="/o-mnie">O mnie</a></li>
        <li><a href="/kontakt">Kontakt</a></li>
      </ul>
    </nav>
  </header>

  <main>
    <article>
      <h2>Tytuł artykułu</h2>
      <p>Treść wpisu...</p>
    </article>
  </main>

  <footer>
    <p>© 2026 Moja strona</p>
  </footer>
</body>
Semantyczny HTML poprawia SEO, dostępność (czytniki ekranu) i czytelność kodu dla innych deweloperów.
Formatowanie tekstu

Podstawy Formatowania Tekstu i Kolory w HTML

Znaczniki Treści

  • <h1> do <h6> – nagłówki hierarchiczne (jeden <h1> na stronę!).
  • <p> – akapit tekstu (podstawa czytelności).
  • <br> – wymuszenie nowego wiersza (samozamykający).
  • <strong> – ważne wyróżnienie pogrubione (dawniej <b>).
  • <em> – akcent / kursywa (dawniej <i>).
  • <del> – tekst przekreślony (usunięty).
  • <sup> i <sub> – m2, H2O.
  • <blockquote> – długi cytat z innego źródła.
  • <hr> – linia pozioma, separator treści.

Kolory: Nazwy, HEX, RGB, HSL

Hipertekst

Odnośniki (<a href="...">) i Podstawy Formularzy

Rodzaje Linków

  • Do innej strony:
    <a href="https://ideis.pl">Portal Uczelni</a>
  • Nowa karta (z bezpieczeństwem):
    <a href="..." target="_blank" rel="noopener noreferrer">
  • Pobieranie pliku:
    <a href="materialy.zip" download>Pobierz</a>
  • Wysyłka e-mail:
    <a href="mailto:nauczanie@pm.me">Napisz</a>
  • Kotwica (anchor):
    <a href="#kontakt">Skocz do kontaktu</a>
target="_blank" bez rel="noopener" → podatność na atak tabnabbing (przejęcie okna nadrzędnego)!

Podstawy Formularzy

<form action="/wyslij" method="POST">
  <label for="email">E-mail:</label>
  <input type="email"
         id="email"
         name="email"
         required>

  <label for="wiadomosc">Wiadomość:</label>
  <textarea id="wiadomosc"
             name="wiadomosc"
             rows="4"></textarea>

  <button type="submit">Wyślij</button>
</form>

Walidacja required i type="email" – wbudowana w HTML5, bez JavaScriptu!

Fundament #2 – CSS

CSS – Oddzielenie Wyglądu od Treści

Kaskadowe Arkusze Stylów odpowiadają za całą warstwę wizualną: kolory, typografię, odstępy, układ i animacje.

Trzy Filary Kaskadowości:

  1. Hierarchia źródeł: Styl inline > <style> w head > Zewnętrzny plik .css
  2. Specyficzność selektora: ID (100) > Klasa (10) > Element (1)
  3. Kolejność zapisu: W razie równej wagi wygrywa reguła niżej w pliku.
Najlepsza praktyka: Style trzymamy w osobnym pliku .css – nigdy nie mieszamy style="..." w HTML! 
/* Anatomia reguły CSS */
selektor {
  właściwość: wartość;
}

/* Przykład 1: element */
h1 {
  color: #38bdf8;
  font-size: 2.5rem;
  letter-spacing: -0.02em;
}

/* Przykład 2: klasa */
.karta-produktu {
  background-color: #0f172a;
  border-radius: 12px;
  padding: 20px;
  border: 1px solid rgba(255,255,255,0.08);
}

/* Przykład 3: ID */
#menu-glowne {
  position: fixed;
  top: 0;
  width: 100%;
}

Układ strony

Pozycjonowanie Elementów: Flexbox vs CSS Grid

Flexbox – Układ 1D

Idealny do pasków nawigacji, wyrównywania elementów w wierszu lub kolumnie:

.flex-nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 15px;
}

/* Elementy nawigacji */
.flex-nav li {
  list-style: none;
  flex: 0 0 auto; /* nie rozciągaj */
}

justify-content: oś główna | align-items: oś poprzeczna

CSS Grid – Układ 2D

Idealny do struktury całych podstron i responsywnych siatek kart:

.siatka-artykulow {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(280px, 1fr));
  gap: 20px;
}

/* Układ nagłówek / treść / sidebar */
.layout {
  display: grid;
  grid-template-areas:
    "header header"
    "main   sidebar"
    "footer footer";
}

auto-fit + minmax – responsywna siatka bez media queries!

Dynamika wizualna

Animacje i Efekty Przejścia w CSS

Współczesna strona reaguje na akcje użytkownika mikrointerakcjami – czysty CSS bez JavaScriptu!

Złota zasada (GPU):

Animujemy wyłącznie transform i opacity. Przeglądarka przekazuje te obliczenia karcie graficznej – stałe 60 FPS nawet na smartfonach.

Unikaj animowania: width, height, top, left, margin – to powoduje kosztowny reflow (przeliczenie układu). 
/* Efekt uniesienia karty */
.karta-artykulu {
  background: #1e293b;
  border-radius: 10px;
  transition: transform 0.3s ease,
              box-shadow 0.3s ease;
}
.karta-artykulu:hover {
  transform: translateY(-6px) scale(1.02);
  box-shadow: 0 12px 30px rgba(0,0,0,0.4);
}

/* Animacja keyframes */
@keyframes pojawienie {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
.element-startowy {
  animation: pojawienie 0.5s ease-out both;
}
Punkt Zwrotny Wykładu

A Jakby Podejść do Tematu Całkowicie Inaczej?

Napisanie strony w HTML i CSS to świetna lekcja inżynierii, ale wyobraźmy sobie klienta, który codziennie publikuje 5 wpisów, zmienia ceny i dodaje zdjęcia galerii...

Czysty Kod (Sam HTML & CSS):

  • Każda literówka = edycja pliku + ponowne wdrożenie.
  • Klient musi znać HTML i boi się, że „zepsuje layout".
  • Brak bazy danych, wyszukiwarki, ról użytkowników.
  • Treść i wygląd pomieszane w jednym pliku.

System CMS (Content Management):

  • Edycja treści w przeglądarce w intuicyjnym edytorze.
  • Pełna separacja treści od szaty graficznej (szablony).
  • Klient zarządza mediami i artykułami bez programisty.
  • Wbudowane: SEO, role użytkowników, wielojęzyczność.
Zarządzanie treścią

Co to Jest CMS i Jakie Funkcje Zapewnia?

CMS (Content Management System) to aplikacja internetowa umożliwiająca tworzenie, modyfikację i organizację treści cyfrowych bez edycji kodu źródłowego.

Kluczowe Funkcje CMS:

  • Proste dodawanie artykułów, stron i produktów.
  • Zarządzanie biblioteką mediów (zdjęcia, filmy, dokumenty).
  • System ról i uprawnień (Autor, Redaktor, Administrator).
  • Silnik szablonów – separacja wyglądu od treści.
  • Rozszerzalność: wtyczki / moduły / REST API.
  • Intuicyjna optymalizacja pod SEO.

Open Source vs Zamknięty SaaS

→ Open Source (nasz wybór):

  • Pełny dostęp do kodu – brak opłat licencyjnych.
  • Instalacja na własnym serwerze (Linux / kontener).
  • Najbardziej rozwojowe i elastyczne.
  • WordPress, Joomla, Ghost CMS.

→ Zamknięty SaaS:

  • Wix, Squarespace, Shopify, Bitrix24.
  • Szybki start, ale wysokie abonamenty i vendor lock-in.
  • Brak dostępu do kodu → brak możliwości głębszej modyfikacji.
Filary semestru

Wielka Trójka CMS w Naszym Programie

W tym semestrze przetestujemy trzy zupełnie różne filozofie podejścia do zarządzania treścią.

Rynkowy Gigant

WordPress

~40% globalnego internetu. Najpopularniejszy CMS z gigantycznym ekosystemem motywów i wtyczek. Zbadamy dlaczego bywa krytykowany i jak używać go profesjonalnie (Gutenberg, Headless WP REST API).

Struktura & ACL

Joomla 5

Potęga ról i uprawnień. Wielojęzyczność z pudełka, wzorzec MVC, wielopoziomowe uprawnienia ACL. Niezastąpiony w portalach publicznych i intranetach korporacyjnych.

Nowoczesność

Ghost CMS

Node.js & Markdown. Błyskawiczna wydajność, czysty Content API, wbudowane subskrypcje i newsletter, genialny edytor. Ulubieniec deweloperów i twórców publikacji online.

CMS #1

WordPress – Dlaczego „Ble", a Dlaczego Musimy Go Znać?

Ciemna strona („ble"):

  • Piekło wtyczek (Plugin Hell): 40 wtyczek = konflikty i spowolnienie.
  • Główny cel botów: 95% włamań = nieaktualne wtyczki firm trzecich.
  • Ociężałe Page Buildery: Divi, Elementor generują gigantyczny, nieoptymalny kod HTML.
  • Baza danych pod każdym requestem – bez cache = wolna strona.

Podejście inżynierskie (2026/27):

  • Edytor Gutenberg & FSE: Natywne bloki bez kombajnów firm trzecich.
  • Headless WordPress: WP jako panel redakcyjny wystawiający dane przez WP REST API → frontend w Astro / React.
  • Hardening: Wyłączenie XML-RPC, limit prób logowania, stałe aktualizacje.
  • Minimalna liczba wtyczek = bezpieczeństwo i wydajność.
WordPress to ~40% internetu – nawet jeśli nie lubisz, rynek wymaga jego znajomości. Nauczymy się używać go mądrze.
CMS #2

Joomla 5 – Inżynierski Porządek i Architektura Uprawnień

Joomla to platforma wybierana tam, gdzie WordPress okazuje się zbyt chaotyczny pod kątem praw dostępu i struktury treści.

Mocne strony Joomli:

  • Zaawansowane ACL: Dowolnie zagnieżdżane grupy użytkowników z precyzyjnymi prawami do podglądu, edycji i publikacji każdego elementu.
  • Natywna wielojęzyczność: Obsługa wielu wersji językowych bez płatnych rozszerzeń.
  • Wzorzec MVC: Czysty podział na Model, Widok i Kontroler w komponentach.
  • Joomla 5 & Web Services API: Nowoczesne REST API do integracji z zewnętrznymi systemami.

Gdzie spotkasz Joomlę?

  • Uczelnie wyższe i instytucje edukacyjne.
  • Serwisy samorządowe i administracji publicznej (BIP).
  • Intranety korporacyjne z podziałem na działy firmy.
  • Portale wielojęzyczne obsługiwane przez wiele grup redaktorów.
Joomla wymaga więcej nauki na starcie, ale dostarcza znakomitą, powtarzalną strukturę danych i uprawnień.
CMS #3 – Nowość w programie

Ghost CMS – Minimalizm, Node.js i Czysty Markdown

Ghost powstał jako bezpośrednia odpowiedź na przekombinowanie WordPressa. Cel: doskonała publikacja treści.

Dlaczego deweloperzy uwielbiają Ghosta?

  • Architektura Node.js: Błyskawiczne czasy odpowiedzi, niskie zużycie zasobów.
  • Edytor Markdown + Karty: Pisanie z formatowaniem kodu bez rozpraszaczy.
  • Natywne Content API: Ghost jako Headless CMS dla dowolnego frontendu (Astro!).
  • Newsletter & Memberships: Wbudowane subskrypcje czytelników.
  • Wyniki Lighthouse > 95: Ekstremalna wydajność bez konfiguracji cache.
// Pobranie wpisów z Ghost Content API
import GhostContentAPI from '@tryghost/content-api';

const api = new GhostContentAPI({
  url: 'http://localhost:2368',
  key: '22444f78447824223ce6a7c059',
  version: "v5.0"
});

// Pobieramy wpisy jako czysty JSON
const posts = await api.posts.browse({
  limit: 5,
  include: 'tags,authors',
  filter: 'featured:true'
});

// Każdy post to obiekt z polami:
// title, html, excerpt, published_at...
Ghost + Astro = ultraszybka strona w pełni statyczna, zasilana z panelu redakcyjnego.

Most do przyszłości

Frameworki Frontendowe i Astro – Wstęp

Świat Frameworków JS

  • React: Nr 1 w ilości pobrań frontendowych – budujemy z komponentów JS. W podobnym kierunku idzie Angular czy Vue.
  • Tailwind CSS: Utility-First CSS – zamiast klas semantycznych używamy mikroklas bezpośrednio w HTML.
  • Bootstrap 5: Nadal popularny, świetny do szybkiego prototypowania i projektów bez designera.

Astro – Architektura Wysp (Islands)

  • Kompiluje kod do czystego HTML + CSS (Zero JS by default!).
  • JavaScript ładowany tylko dla elementów, które są naprawdę interaktywne.
  • Niezrównane wyniki Lighthouse – idealne dla blogów, portfeli, stron firmowych.
  • Obsługuje komponenty React, Vue, Svelte jednocześnie!
W tym semestrze połączymy świat CMS ze światem nowoczesnych frameworków – np. pobierając treści z Ghosta lub WordPressa do ultraszybkiego serwisu w Astro!
