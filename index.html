Filary technologiczne

Wielka Trójka CMS w Praktyce

Trzy różne filozofie zarządzania treścią, które opanujesz w tym semestrze.

WordPress

Klasyczny rynkowy monolit. Uczymy się jak nie dać się zwieść "piekłu wtyczek", tworzyć bezpieczne instalacje i używać WP jako headless API.

  • Największy udział rynkowy (~40%)
  • Potężne REST API w wersji natywnej
  • Edytor blokowy Gutenberg / FSE

Joomla 5

Inżynierski porządek architektoniczny. Niezrównana w budowie serwisów z hierarchicznym dostępem i wbudowaną obsługą wielu języków.

  • Zaawansowany model uprawnień (ACL)
  • Pełna wielojęzyczność bez dodatków
  • Architektura MVC dla komponentów

Ghost CMS

Świeży powiew w świecie publikacji. Błyskawiczny silnik Node.js, doskonały edytor Markdown, subskrypcje i czyste Content API dla frontendu.

  • Ekstremalna wydajność i szybkość
  • Intuicyjny edytor Markdown & Cards
  • Idealny do architektury Jamstack
